# 言葉の決まり

利用者が指示した呼び方。新しく書く文は、これに従う。

| 使わない | 使う | いつ決めたか |
|---|---|---|
| 雪像 | スナップショット | 2026-11-12 (「雪像ってあんま言わないからスナップショットって言うように」) |
| Phase (まとまりの単位) | タスク | 2026-10-23 |
| `T.34.21` | `T34.21` | 2026-11-05 |
| `--criteria phaseNN` (新しく足す判定表) | `--criteria T<タスクの番号>` | 2026-11-07 |

## 当てはめ方

- 新しく書く文 (報告・台帳・README・docs・コメント・コミットメッセージ) に当てはめる。
- 済んだタスクの記録 (`tasks/TNN.md`) は 1 文字も変えない決まりなので、古い言葉のまま残す。
- 道具の出力のうち、過去の判定を同じ命令で出し直すために凍結しているもの (`scripts/snapshot_criteria.py`・`scripts/criteria/`・`scripts/snapshot-diff.py` の phase30 までの文字列) は変えない。
- 既にある文をまとめて置き換えるのは、利用者が頼んだときだけ。
