読み方

  • (1) の往復の中央値が「この端末 → プロキシの RTT + /status を組んで返す時間」です。同じ機械の中 (loopback) なら 1 ms 前後、遠いところにあるなら回線の RTT がそのまま出ます。
  • (2) の判定はプロキシの記録で見ます: プロキシは自分宛ての要求 (/status など) を clients[] に数えないので、URL を取る前後で自分の行の requests が増えていれば「このブラウザはプロキシを経由した」、増えていなければ「経由していない (端末が自分で取りに行った)」です。自分の IP は、増えた行から分かります (増えた行が無いときは /clients の「最終が今」の行を見当にします)。
  • (3) の rtt_ms はカーネルが測った平滑化 RTT (T14.5) で、接続を閉じたときに 1 本ぶん読んだものです。(1) の往復からこの RTT を引いた残りが「プロキシが応答を組むのにかかった時間 + 端末の中の時間」です。このページを開いている接続はまだ閉じていないので、標本が 0 なら「–」になります。
  • --lite (PROXY_PROFILE=lite) では接続元を記録していません。このページは開けますが (3) の表は空で、(2) は判定できません。
  • 測った値はサーバーに送りません。残したいときはこの画面を保存するか、/snapshot を手で取ってください。
