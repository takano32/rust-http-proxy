- [x] **T38.0 `conn` 役の CPU の行を、要求の数で動かない形にする**
  - 目的: T37.99 で 1.30 倍の届かず。要求が 2,102 → 1,378 本/時 (0.66 倍) に減り、開いたトンネルの中継のように時間で払う費用を少ない要求で割ったので 1 本あたりが上がった (CPU の合計は減っていた)。
  - やること: `conn` 役の CPU を「要求の数で払う分」と「時間で払う分」(開いていたトンネルの本数 × 時間、中継したバイトなど) に分けて読める材料が、いまのスナップショットにあるかを確かめる。あれば両方を前の版と比べる行に、無ければ要求の量が前の版と大きく違うとき (例: 0.8〜1.25 倍の外) は「判定できず」にして理由を書く。どちらにするかは材料を見て決め、判定表 `T38` に入れる。

  - 結果 (2026-11-19、`a80f592`): 「要求の量が大きく違えば判定できず」の道にした。時間で払う分の量 (`/profile` の `conn` 役の標本の数、`/history` の `active`・`bytes_delta`) はスナップショットにあるが、`conn` 役の CPU は 1 分ごとの和 1 つだけで、回帰で分けると係数が前後でそろわない (1 時間ごとの決定係数 0.91 / 0.75、1 分ごとでは 0.24)。分けた値で判定すると回帰のぶれで決まるので使わない。
